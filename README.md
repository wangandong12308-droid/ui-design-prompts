# ui-design-prompts

页面与交互设计提示词库：34 分类、348 条可直接复制的详细提示词，外加一个可浏览的合集站。

## 这是什么

- **合集站**（`docs/`，可用 GitHub Pages 打开）：34 分类、280 条交互模式，每条有“是什么、实现要点（含可落地的时长 / 阈值 / 尺寸 / 色值）、适用场景”。它是检索用的索引。
- **提示词文档**（`prompts/`）：348 条“给 AI 的详细提示词”，按 `## 提示词：XXX` 分节，每条有适用场景、整段提示词原文、关键数值、来源。应用时原样输出，不要改写。
- **SKILL.md**：给 agent 用的工作流程——先鉴别风格（从用途和用户需求出发），再检测需求、按意图路由表定位到对应条目、原样应用。

## 使用方法

1. 用户说出想做的界面或交互。
2. Agent 按 `SKILL.md` 的流程：鉴别风格 → 检测需求 → 定位条目 → 原样输出提示词。
3. 只改变量部分（产品名、文案、颜色、尺寸单位），并在输出里标出改了哪里；数值带“约”的是落地建议值、非官方规范，落地前对照当期官方文档复核。

## 目录结构

- `SKILL.md`：工作流程与意图路由表。
- `docs/`：合集站静态页（GitHub Pages 源）。
- `prompts/`：348 条提示词文档。
