通用基准速记

  • 动效时长（M3）：短档 50–200ms、中档 250–400ms、长档 450–600ms，强调动效约 500ms
  • iOS 弹簧：默认阻尼 1.0、响应约 0.4s；抽屉 / 表单约 0.8 / 0.3s
  • 触控目标：iOS 约 44pt、Android 约 48dp，小于这个尺寸先放大热区
  • 对比度：正文 4.5:1、大字 3:1，图标与描边不低于 3:1

视觉设计与虚拟币速记

  • 字阶：12 / 14 / 16 / 20 / 24 / 32px，正文行高约 1.5–1.7、标题约 1.2–1.3
  • 数字：价格 / 金额 / 倒计时用等宽数字（tabular-nums），跳动时行宽不抖
  • 字体许可：思源 / Noto / LXGW 文楷均为 SIL OFL，但商用、嵌入、改字再分发前须再核对许可原文（LXGW 有保留字名条款）
  • 配色：第 23 类 5 套配色多为组合建议（约值），文字 / 背景组合须用对比度工具实测后才算达标
  • 涨跌色：红涨绿跌与绿涨红跌双轨可切换，且始终配 ↑↓ 箭头与 +/− 号，不只靠颜色
  • 长按币种：约 400–500ms + 轻震动出预览卡与菜单，菜单约 5–6 项，预览卡内不放按钮
